# Quantum Ship

Game about doding the obstacles in a ship using quantum operations and superposition for advantage.

Made using [pygame](https://pypi.org/project/pygame/) for my university course.

## How to setup and run

Requirements:

- Python 3.13
- Pip

```bash
python -m venv .venv

source .venv/bin/activate       # Linux
.venv\Scripts\activate          # Windows + Powershell
source .venv/Scipts/activate    # Windows + Gitbash

pip install -r requirements.txt
python main.py
```
